# Integrator and Differentiator Circuits

## Overview

Op-amp integrator and differentiator circuits perform mathematical operations on input signals, forming the foundation of analog computing. An integrator produces an output proportional to the integral of the input signal, while a differentiator produces an output proportional to the derivative. These circuits can convert between waveform shapes, such as square waves to triangle waves.

## Objective

To practice mathematical operations (integration and differentiation) using op-amp circuits.

## Domain

Analog Electronics — Analog Computing and Signal Processing.

## Components and Equipment

- **Active Components**: LM741 or TL081 op-amp IC
- **Passive Components**: 0.1µF capacitor, 1µF capacitor, 1kΩ, 10kΩ, 100kΩ resistors
- **Equipment**: Dual DC power supply (±12V), Function generator, Oscilloscope

## Required Skills

- Op-amp fundamentals (Lab 08)
- Understanding of calculus concepts (integration, differentiation)
- RC circuit behavior

## Theory and Engineering Concepts

- **Integrator Output**: Vout(t) = -(1/RC) × ∫Vin(t)dt. The output is the time integral of the input, inverted and scaled.
- **Differentiator Output**: Vout(t) = -RC × dVin/dt. The output is the derivative of the input, inverted and scaled.
- **Waveform Conversion**: A square wave input to an integrator produces a triangle wave output. A triangle wave input to a differentiator produces a square wave output.
- **Practical Considerations**: Real integrators need a feedback resistor to prevent DC offset saturation. Real differentiators need a series input resistor to limit high-frequency gain and noise.

## Circuit Configuration

**Integrator**: Capacitor in feedback path (Rf replaced by C), input resistor (Rin) from signal to inverting input.

**Differentiator**: Capacitor in series with input (Cin), feedback resistor (Rf) from output to inverting input.

## Procedure / Implementation

### Step 1: Integrator Circuit

1. Connect the op-amp with ±12V power supply
2. Connect a 10kΩ resistor from signal input to the inverting input
3. Connect a 0.1µF capacitor from output to inverting input (feedback path)
4. Connect a 100kΩ resistor in parallel with the capacitor (for DC stabilization)
5. Apply a 1kHz square wave (2Vpp) input
6. Observe the triangle wave output

### Step 2: Differentiator Circuit

1. Connect a 0.1µF capacitor in series with the signal input
2. Connect a 100Ω resistor in series with the capacitor (stability)
3. Connect a 10kΩ feedback resistor from output to inverting input
4. Apply a 1kHz triangle wave (2Vpp) input
5. Observe the square wave output

### Step 3: Frequency Response

1. Vary the input frequency and observe changes in output amplitude
2. Note the integrator's low-pass characteristic
3. Note the differentiator's high-pass characteristic

## What Was Done

Built circuits to perform mathematical integration and differentiation on input waveforms. Verified the square-to-triangle wave conversion using the integrator and triangle-to-square wave conversion using the differentiator.
