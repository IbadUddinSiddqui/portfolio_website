# Half-Wave Rectifier

## Overview

The half-wave rectifier is the simplest form of rectifier circuit, converting alternating current (AC) to pulsating direct current (DC) using a single diode. While simple and economical, it has low efficiency due to utilizing only one half of the AC cycle. This laboratory session covers the construction, operation, and analysis of the half-wave rectifier.

## Objective

To practice the operation and analysis of a half-wave rectifier circuit using a PN-junction diode and resistive load.

## Domain

Circuit Analysis — Rectification and AC-to-DC Conversion.

## Theory and Engineering Concepts

- **Rectification**: The process of converting AC to DC. A diode conducts only during the positive half-cycle of the AC input (forward bias) and blocks during the negative half-cycle (reverse bias).
- **Half-Wave Operation**: Only one half of the AC waveform appears across the load, resulting in a pulsating DC output.
- **Peak Inverse Voltage (PIV)**: The maximum reverse voltage the diode must withstand. For a half-wave rectifier, PIV = Vm (peak voltage of the input).
- **Ripple Factor**: A measure of the AC component remaining in the rectified output. For an unfiltered half-wave rectifier, ripple factor ≈ 1.21 (121%).
- **Average DC Output**: Vdc = Vm/π ≈ 0.318 × Vm, where Vm is the peak voltage.

## Circuit Configuration

The half-wave rectifier consists of:
- AC input source (transformer secondary or function generator)
- Single diode connected in series with the load
- Load resistor connected between the diode cathode and ground

Signal flow: AC Input → Diode (conducts during positive half-cycle) → Pulsating DC across load

## Procedure / Implementation

### Step 1: Circuit Construction

1. Mount the diode on the breadboard, noting the cathode marking (band)
2. Connect the diode anode to the AC source positive terminal
3. Connect the diode cathode to one end of the 1kΩ load resistor
4. Connect the other end of the load resistor to ground
5. Connect the AC source ground to the same ground point

### Step 2: Testing and Measurement

1. Set the function generator to output a 10Vpp sine wave at 50Hz
2. Connect the oscilloscope Channel 1 to measure the input AC signal
3. Connect oscilloscope Channel 2 to measure the output across the load resistor
4. Apply power to the circuit
5. Observe and sketch both input and output waveforms

### Step 3: Measurements

1. Measure the peak voltage (Vp) of the output waveform
2. Measure the DC voltage using the DMM in DC mode
3. Measure the AC ripple voltage using the DMM in AC mode
4. Record all measurements in a table

## What Was Done

Constructed a half-wave rectifier circuit using a 1N4007 PN-junction diode and a 1kΩ resistive load. The circuit was tested with a 10Vpp, 50Hz sine wave input. The output waveform showed only the positive half-cycles, resulting in pulsating DC.

## What Was Learnt

- The half-wave rectifier circuit clips the negative half-cycle of the AC input, resulting in a pulsating DC output with a high ripple factor
