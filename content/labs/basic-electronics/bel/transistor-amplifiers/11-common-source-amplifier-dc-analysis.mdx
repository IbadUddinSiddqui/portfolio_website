# Common Source Amplifier — DC Analysis

## Overview

The common source (CS) amplifier is a fundamental MOSFET amplifier configuration that provides high voltage gain and high input impedance. Proper DC biasing is critical to ensure the MOSFET operates in the saturation (active) region, enabling linear amplification of AC signals. This laboratory session focuses on the DC analysis of a voltage-divider biased CS amplifier.

## Objective

To try the voltage divider bias-based common source amplifier circuit and perform its DC analysis.

## Domain

Transistor Amplifiers — MOSFET Biasing and DC Operating Point.

- **CLO-3**: Perform DC analysis of MOSFET common source amplifier circuits.

## Components and Equipment

- **Active Components**: N-channel MOSFET (IRF510 or 2N7000)
- **Passive Components**: 10kΩ (RD), 100Ω (RS), 220kΩ (R1), 470kΩ (R2)
- **Equipment**: DC power supply (15V), DMM

- Understanding of MOSFET characteristics
- Voltage divider calculations
- Ohm's law application

## Theory and Engineering Concepts

- **Common Source Configuration**: The source terminal is common (grounded) to both input and output. Signal is applied to the gate, and output is taken from the drain.
- **Voltage Divider Bias**: R1 and R2 form a voltage divider to set the gate voltage: VG = VDD × R2/(R1 + R2).
- **DC Operating Point (Q-Point)**: The DC voltages and currents that define the amplifier's operating region. For saturation: VGS > Vth and VDS > VGS - Vth.
- **MOSFET Drain Current**: In saturation, ID = (1/2) × kn × (VGS - Vth)².
- **Source Voltage**: VS = ID × RS. Gate-Source Voltage: VGS = VG - VS.

## Circuit Configuration

The voltage-divider biased CS amplifier consists of:
- R1 and R2 forming a voltage divider from VDD to gate
- RD (drain resistor) from VDD to drain
- RS (source resistor) from source to ground
- Bypass capacitor (CS) across RS (added later for AC analysis)
- Coupling capacitors at input and output (for AC signal path)

## Procedure / Implementation

### Step 1: Circuit Construction (DC Only)

1. Mount the MOSFET on the breadboard, identifying gate, drain, and source terminals
2. Connect R1 (220kΩ) from VDD (+15V) to the gate
3. Connect R2 (470kΩ) from gate to ground
4. Connect RD (10kΩ) from VDD to drain
5. Connect RS (100Ω) from source to ground
6. Verify all connections before applying power

### Step 2: DC Voltage Measurements

1. Apply +15V DC power to the circuit
2. Measure and record:
   - Gate voltage (VG)
   - Source voltage (VS)
   - Drain voltage (VD)
   - Drain-Source voltage (VDS = VD - VS)
   - Gate-Source voltage (VGS = VG - VS)
3. Calculate the drain current: ID = VS / RS
4. Calculate the expected values using MOSFET equations

### Step 3: Verify Saturation Region

1. Check that VGS > Vth (threshold voltage, typically 1-2V for power MOSFETs)
2. Check that VDS > VGS - Vth (saturation condition)
3. If not in saturation, adjust resistor values to achieve proper biasing

## What Was Done

Set up a common source amplifier with voltage divider bias (R1 = 220kΩ, R2 = 470kΩ, RD = 10kΩ, RS = 100Ω, VDD = 15V) and performed DC biasing analysis by measuring gate, source, and drain voltages.

## What Was Learnt

- Proper DC biasing is critical to ensure the MOSFET operates in the active (saturation) region
- The voltage divider provides a stable gate voltage independent of MOSFET parameters
- The Q-point determines the amplifier's operating range and linearity
- DC analysis must be performed before applying AC signals
- Source resistor (RS) provides DC negative feedback for bias stability
