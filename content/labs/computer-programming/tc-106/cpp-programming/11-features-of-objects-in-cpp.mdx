# Features of Objects in C++ — Advanced OOP

## Overview

C++ provides sophisticated features for working with objects including access control, member functions, constructors, and destructors. Understanding these features is essential for writing robust, maintainable object-oriented programs. This laboratory session explores the advanced features of objects in C++.

## Objective

To investigate different features of objects in C++, including access specifiers, public and private members, and class member functions.

## Domain

Software — Advanced Object-Oriented Programming.

## Taxonomy Level

P3 — Supervised Practice (Practical application of advanced OOP features under guidance).

## Tools and Technologies

- **Software**: Turbo C++ IDE 3.0
- **Language**: C++

## Required Skills

- Basic OOP concepts (Lab 10)
- Understanding of classes and objects

## Concepts Covered

- **Private Members**: Data and functions accessible only within the class (data hiding)
- **Public Members**: Data and functions accessible from outside the class
- **Access Specifiers**: public, private, protected — control visibility of class members
- **Member Functions**: Functions defined inside a class that operate on class data
- **Constructor**: A special member function called automatically when an object is created
- **Destructor**: A special member function called automatically when an object is destroyed
- **Data Hiding**: Encapsulating data as private and providing controlled access through public methods

## Project / Task

Create a quadratic equation solver using OOP. The program should use a class with private data members for coefficients and public methods for calculations.

## Implementation

### Step 1: Class with Private Members

1. Create a class demonstrating data hiding:
   ```cpp
   #include <iostream.h>
   #include <conio.h>
   #include <math.h>

   class Quadratic {
   private:
       float a, b, c;          // Coefficients (private - data hiding)
       float discriminant;

       void calculateDiscriminant() {
           discriminant = b * b - 4 * a * c;
       }

   public:
       void setCoefficients(float x, float y, float z) {
           a = x;
           b = y;
           c = z;
           calculateDiscriminant();
       }

       void findRoots() {
           float root1, root2;
           if(discriminant >= 0) {
               root1 = (-b + sqrt(discriminant)) / (2 * a);
               root2 = (-b - sqrt(discriminant)) / (2 * a);
               cout << "Roots are real and distinct:\n";
               cout << "Root 1 = " << root1 << endl;
               cout << "Root 2 = " << root2 << endl;
           } else if(discriminant == 0) {
               root1 = -b / (2 * a);
               cout << "Roots are real and equal:\n";
               cout << "Root = " << root1 << endl;
           } else {
               cout << "Roots are imaginary" << endl;
           }
       }
   };

   void main() {
       Quadratic eq;
       float a, b, c;
       clrscr();

       cout << "Quadratic Equation Solver" << endl;
       cout << "Enter coefficients a, b, c: ";
       cin >> a >> b >> c;

       eq.setCoefficients(a, b, c);
       eq.findRoots();

       getch();
   }
   ```

### Step 2: Constructor Example

1. Add a constructor to the class:
   ```cpp
   class Student {
   private:
       int rollNo;
       char name[30];
       float marks;

   public:
       // Constructor
       Student() {
           rollNo = 0;
           marks = 0.0;
           cout << "Object created!" << endl;
       }

       void setData(int r, char n[], float m) {
           rollNo = r;
           strcpy(name, n);
           marks = m;
       }

       void display() {
           cout << "Roll No: " << rollNo << endl;
           cout << "Name: " << name << endl;
           cout << "Marks: " << marks << endl;
       }
   };
   ```

### Step 3: Multiple Objects Demonstration

1. Create multiple objects to show independence:

   ```cpp
   void main() {

       cout << "Student 1:\n";
       s1.display();

       s2.display();

       getch();
   }
   ```
