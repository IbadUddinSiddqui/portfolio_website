# Pointers in C — Memory Management

## Overview

Pointers are one of the most powerful features of C, providing direct access to memory addresses. They enable dynamic memory allocation, efficient array and string manipulation, and call-by-reference function parameters. This laboratory session covers pointer concepts from basic declaration to dynamic memory management.

## Objective

To apply the concept of pointers in C for memory management, dynamic allocation, and efficient string processing.

## Domain

Software — Memory Management and Low-Level Programming.

## Taxonomy Level

P3 — Supervised Practice (Practical application of pointers under guidance).

## Tools and Technologies

- **Software**: Turbo C++ IDE 3.0
- **Language**: C

## Required Skills

- Arrays and indexing (Lab 08)
- Functions (Lab 07)
- Understanding of computer memory concepts

## Concepts Covered

- **Pointer Declaration**: `int *ptr;` — declares a pointer to an integer
- **Address-of Operator (&)**: Returns the memory address of a variable
- **Dereference Operator (*)**: Accesses the value at a memory address
- **Pointer Arithmetic**: Adding/subtracting moves to adjacent memory locations
- **Pointer and Arrays**: Array name is a constant pointer to the first element
- **Dynamic Memory Allocation**: malloc(), calloc(), free() for runtime memory
- **NULL Pointer**: A pointer that points to nothing (safety check)

## Project / Task

Implement programs for dynamic memory allocation and string processing using pointers.

## Implementation

### Step 1: Basic Pointer Operations

1. Create a program demonstrating pointer basics:
   ```c
   #include <stdio.h>
   #include <conio.h>

   void main() {
       int var = 25;
       int *ptr;
       clrscr();

       ptr = &var;  // ptr now holds the address of var

       printf("Value of var = %d\n", var);
       printf("Address of var = %p\n", &var);
       printf("Value of ptr (address) = %p\n", ptr);
       printf("Value at address pointed by ptr = %d\n", *ptr);

       getch();
   }
   ```

### Step 2: Pointers and Arrays

1. Demonstrate array-pointer relationship:
   ```c
   #include <stdio.h>
   #include <conio.h>

   void main() {
       int arr[] = {10, 20, 30, 40, 50};
       int *ptr = arr;  // Points to first element
       int i;
       clrscr();

       printf("Using array indexing:\n");
       for(i = 0; i < 5; i++) {
           printf("arr[%d] = %d\n", i, arr[i]);
       }

       printf("\nUsing pointer arithmetic:\n");
       for(i = 0; i < 5; i++) {
           printf("*(ptr + %d) = %d\n", i, *(ptr + i));
       }

       getch();
   }
   ```

### Step 3: Dynamic Memory Allocation

1. Use malloc to allocate memory at runtime:
   ```c
   #include <stdio.h>
   #include <conio.h>
   #include <stdlib.h>

   void main() {
       int *arr;
       int n, i;
       clrscr();

       printf("Enter number of elements: ");
       scanf("%d", &n);

       // Allocate memory dynamically
       arr = (int*)malloc(n * sizeof(int));

       if(arr == NULL) {
           printf("Memory allocation failed!");
           getch();
           return;
       }

       printf("Enter %d elements:\n", n);
       for(i = 0; i < n; i++) {
           scanf("%d", &arr[i]);
       }

       printf("You entered:\n");
       for(i = 0; i < n; i++) {
           printf("%d ", arr[i]);
       }

       free(arr);  // Free allocated memory
       getch();
   }
   ```

### Step 4: String Processing with Pointers

1. Process a string using pointers:
   ```c
   #include <stdio.h>
   #include <conio.h>

   void main() {
       char str[] = "Hello World";
       char *ptr = str;
       clrscr();

       printf("String: ");
       while(*ptr != '\0') {
           printf("%c", *ptr);
           ptr++;
       }

       getch();
   }
   ```
