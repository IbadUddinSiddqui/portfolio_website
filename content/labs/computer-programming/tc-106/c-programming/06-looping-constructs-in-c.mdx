# Looping Constructs in C

## Overview

Loops are fundamental programming constructs that allow a block of code to be executed repeatedly based on a condition. C provides three types of loops: for, while, and do-while. This laboratory session covers all three loop types and teaches students when to use each one effectively.

## Objective

To apply looping constructs in C: for, while, and do-while loops for iterative program execution.

## Domain

Software — Programming Logic and Control Flow.

## Taxonomy Level

P3 — Supervised Practice (Practical application of loops under guidance).

- **Software**: Turbo C++ IDE 3.0
- **Language**: C

## Required Skills

- Conditional statements (Lab 05)
- Variable manipulation

## Concepts Covered

- **for Loop**: Used when the number of iterations is known in advance. Syntax: for(initialization; condition; increment/decrement)
- **while Loop**: Used when the number of iterations is not known. Syntax: while(condition) { body }
- **do-while Loop**: Similar to while but guarantees at least one execution. Syntax: do { body } while(condition);
- **Nested Loops**: Loops inside loops, useful for 2D patterns and matrix operations
- **Break and Continue**: break exits the loop entirely; continue skips to the next iteration

## Project / Task

Generate mathematical sequences, display a multiplication table, and print complex patterns using nested loops.

## Implementation

### Step 1: For Loop — Multiplication Table

1. Create a program to display a multiplication table:
   ```c
   #include <stdio.h>
   #include <conio.h>

   void main() {
       int num, i;
       clrscr();

       printf("Enter a number: ");
       scanf("%d", &num);

       for(i = 1; i <= 10; i++) {
           printf("%d x %d = %d\n", num, i, num * i);
       }

       getch();
   }
   ```

### Step 2: While Loop — Number Sequence

1. Generate a sequence using while:
   ```c
   #include <stdio.h>
   #include <conio.h>

   void main() {
       int i = 1, n;
       clrscr();

       printf("Enter limit: ");
       scanf("%d", &n);

       while(i <= n) {
           printf("%d ", i);
           i++;
       }

       getch();
   }
   ```

### Step 3: Do-While Loop — Menu System

1. Create a menu that displays at least once:
   ```c
   #include <stdio.h>
   #include <conio.h>

   void main() {
       int choice;
       clrscr();

       do {
           printf("\n1. Option 1");
           printf("\n2. Option 2");
           printf("\n3. Exit");
           printf("\nEnter choice: ");
           scanf("%d", &choice);

           switch(choice) {
               case 1: printf("Option 1 selected\n"); break;
               case 2: printf("Option 2 selected\n"); break;
               case 3: printf("Exiting...\n"); break;
               default: printf("Invalid\n");
           }
       } while(choice != 3);

       getch();
   }
   ```

### Step 4: Nested Loops — Pattern Printing

1. Create a star pattern:
   ```c
   #include <stdio.h>
   #include <conio.h>

   void main() {
       int i, j;
       clrscr();

       for(i = 1; i <= 5; i++) {
           for(j = 1; j <= i; j++) {
               printf("* ");
           }
           printf("\n");
       }

       getch();
   }
   ```
