# Basic Building Blocks of C — Data Types and I/O

## Overview

C is a strongly-typed programming language where every variable must be declared with a specific data type before use. This laboratory session covers the fundamental building blocks of C programming: data types, variables, constants, and input/output functions. These elements form the foundation for all C programs.

## Objective

To study basic building blocks of the C language such as data types and input-output functions. To declare variables of appropriate types and use printf/scanf for console I/O.

## Domain

Software — Programming Language Fundamentals.

## Concepts Covered

- **Keywords**: Reserved words in C (int, float, char, void, return, etc.)
- **Data Types**: int (integers), float (decimal numbers), char (single characters), double (higher precision)
- **Variables**: Named memory locations that store values of specific types
- **Format Specifiers**: %d (int), %f (float), %c (char), %s (string), %lf (double)
- **Escape Sequences**: \n (new line), \t (tab), \b (backspace)
- **printf()**: Output function for displaying text and variable values
- **scanf()**: Input function for reading user input
- **Constants**: Fixed values that cannot change during program execution

## Project / Task

Write a program to calculate the area of a circle. The program should take the radius as user input and display the calculated area.

## Implementation

### Step 1: Program Design

1. Plan the program logic:
   - Declare variables for radius (float) and area (float)
   - Prompt the user to enter the radius
   - Read the radius using scanf
   - Calculate area = π × r²
   - Display the result

### Step 2: Write the Program

1. Create a new file in Turbo C IDE
2. Type the following program:
   ```c
   #include <stdio.h>
   #include <conio.h>
   #define PI 3.14159

   void main() {
       float radius, area;
       clrscr();

       printf("Enter the radius of the circle: ");
       scanf("%f", &radius);

       area = PI * radius * radius;

       printf("\nRadius = %.2f units", radius);
       printf("\nArea = %.2f square units", area);

       getch();
   }
   ```

### Step 3: Understanding the Code

1. `#define PI 3.14159` — Defines a constant PI with value 3.14159
2. `float radius, area;` — Declares two floating-point variables
3. `scanf("%f", &radius);` — Reads a float value from the user and stores it in the variable `radius`. The `&` operator gives the memory address of the variable
4. `area = PI * radius * radius;` — Calculates the area using the formula
5. `printf("\nRadius = %.2f units", radius);` — Prints the radius with 2 decimal places

### Step 4: Compile and Execute

1. Save the file as `AREA.C`
2. Compile (Alt+F9) and fix any errors
3. Link (F9) and run (Ctrl+F9)
4. Enter a value when prompted (e.g., 5)
5. Verify the output: Area = 78.54 square units

### Step 5: Experiment with Data Types

1. Modify the program to use `int` instead of `float` for radius
2. Observe what happens when entering decimal values
3. Experiment with different format specifiers: %d, %c, %s

## What Was Done
