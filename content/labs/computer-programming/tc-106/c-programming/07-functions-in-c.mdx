# Functions in C — Modular Programming

## Overview

Functions are the building blocks of modular programming in C. They allow code to be organized into reusable, self-contained units that perform specific tasks. This laboratory session covers all aspects of functions including declaration, definition, parameter passing, return values, and recursion.

## Objective

To explore functions in C, including function declaration, definition, calling conventions, parameter passing mechanisms, and recursive functions.

## Domain

Software — Modular Programming and Code Organization.

## Taxonomy Level

P3 — Supervised Practice (Practical application of functions under guidance).

- **Software**: Turbo C++ IDE 3.0
- **Language**: C

## Concepts Covered

- **Function Declaration (Prototype)**: Tells the compiler about a function's name, return type, and parameters before its definition
- **Function Definition**: The actual body of the function containing the code to execute
- **Function Call**: Invoking a function to execute its code
- **Parameters**: Input values passed to a function (formal vs. actual parameters)
- **Return Values**: The value a function sends back to the caller
- **Call by Value**: A copy of the argument is passed; changes don't affect the original
- **Recursion**: A function that calls itself

## Project / Task

Create modular programs using functions: implement a swapping function, a recursive factorial calculator, and a modular program with multiple functions.

## Implementation

### Step 1: Basic Function

1. Create a program with a user-defined function:
   ```c
   #include <stdio.h>
   #include <conio.h>

   // Function declaration (prototype)
   int add(int a, int b);

   void main() {
       int x = 10, y = 20, result;
       clrscr();

       // Function call
       result = add(x, y);
       printf("Sum = %d", result);

       getch();
   }

   // Function definition
   int add(int a, int b) {
       return a + b;
   }
   ```

### Step 2: Swapping Function

1. Implement a function to swap two numbers:
   ```c
   #include <stdio.h>
   #include <conio.h>

   void swap(int *a, int *b);  // Using pointers for call by reference

   void main() {
       int x = 10, y = 20;
       clrscr();

       printf("Before swap: x = %d, y = %d\n", x, y);
       swap(&x, &y);
       printf("After swap: x = %d, y = %d\n", x, y);

       getch();
   }

   void swap(int *a, int *b) {
       int temp = *a;
       *a = *b;
       *b = temp;
   }
   ```

### Step 3: Recursive Function — Factorial

1. Implement factorial using recursion:
   ```c
   #include <stdio.h>
   #include <conio.h>

   int factorial(int n);

   void main() {
       int num;
       clrscr();

       printf("Enter a number: ");
       scanf("%d", &num);
       printf("Factorial of %d = %d", num, factorial(num));

       getch();
   }

   int factorial(int n) {
       if (n <= 1)
           return 1;
       else
           return n * factorial(n - 1);
   }
   ```
