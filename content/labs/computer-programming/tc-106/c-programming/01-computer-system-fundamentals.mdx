# Computer System Fundamentals

## Overview

Understanding computer system fundamentals is the foundation of all programming and software engineering. This laboratory session provides hands-on experience with computer hardware components, peripheral devices, and the internal architecture of a computer system. Students learn to identify, handle, and understand the role of each component in a modern computer.

## Objective

To provide students with hands-on experience to understand the basic components of a computer system, the role of peripherals, and the functional units of a CPU.

## Domain

Hardware — Computer System Architecture and Organization.

## Taxonomy Level

P3 — Supervised Practice (Practical application of hardware knowledge under guidance).

## Tools and Technologies

- **Hardware**: Computer system (laptop/desktop), Keyboard, Mouse, Monitor, CPU chip, Motherboard, RAM modules, Hard drive, Power supply unit
- **Tools**: Screwdriver set, Anti-static wrist strap, Cable management ties
- **Software**: Operating system (Windows/Linux) for system information verification

## Required Skills

- Careful equipment handling
- Safe opening and closing of computer cases
- Basic peripheral interaction and identification

## Concepts Covered

- **Computer System Components**: The major subsystems including input devices, output devices, processing unit, and storage
- **CPU Architecture**: The Central Processing Unit as the brain of the computer, containing the Control Unit (CU), Arithmetic Logic Unit (ALU), and registers
- **Motherboard**: The main circuit board connecting all components via buses and chipset
- **Memory Hierarchy**: RAM (volatile, fast) vs. Storage (non-volatile, slower)
- **Peripherals**: Input devices (keyboard, mouse) and output devices (monitor, printer)
- **Safety Practices**: Electrostatic discharge (ESD) protection, proper handling procedures

## Project / Task

Interactive exploration and inspection of computer peripherals and internal CPU/motherboard components. Identify and document each major component of a computer system.

## Implementation

### Step 1: External Peripheral Identification

1. Examine the external peripherals connected to the computer:
   - **Input Devices**: Keyboard, mouse, microphone, webcam
   - **Output Devices**: Monitor, speakers, printer
   - **Connectivity**: USB ports, HDMI/VGA ports, audio jacks, Ethernet port
2. Identify the data flow direction for each peripheral (input, output, or both)
3. Document the purpose of each peripheral

### Step 2: Safe Computer Case Opening

1. Power off the computer and disconnect all cables
2. Use an anti-static wrist strap to prevent ESD damage
3. Place the computer on a clean, flat surface
4. Remove the side panel screws using a screwdriver
5. Slide the side panel off to expose internal components

### Step 3: Internal Component Identification

1. **Motherboard**: Locate the main circuit board — identify:
   - CPU socket with cooling fan/heat sink
   - RAM slots (DIMM slots)
   - Expansion slots (PCIe)
   - Chipset (northbridge/southbridge)
   - BIOS/UEFI chip
   - SATA connectors for storage
   - Power connectors (ATX)
2. **Power Supply Unit (PSU)**: Locate the power supply and trace its connections
3. **Storage Devices**: Identify hard disk drive (HDD) or solid-state drive (SSD)
4. **RAM Modules**: Identify and note the DDR type and capacity

### Step 4: CPU and Motherboard Inspection

1. If permitted, remove the CPU cooler to expose the CPU
2. Identify the CPU and note its specifications (model, socket type, core count)
3. Trace the data path: CPU → RAM → Storage
4. Identify the front panel connectors and their purpose

### Step 5: Reassembly

1. Replace the side panel carefully
2. Secure with screws
3. Reconnect all external cables
4. Power on and verify the system boots correctly

## What Was Done

Performed hands-on interaction with input/output devices, safely opened a computer case, and identified internal components including the motherboard, CPU, RAM modules, storage devices, and power supply. Documented each component's role in the computer system architecture.

## What Was Learnt

- Understanding of elementary computing concepts and hardware component identification
- The importance of safety when handling computer equipment (ESD protection)
- The relationship between input, processing, output, and storage in a computer system
- Practical skills in computer hardware assembly and disassembly
