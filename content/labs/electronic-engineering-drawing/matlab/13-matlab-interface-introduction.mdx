# MATLAB Interface and Environment Introduction

## Overview

MATLAB (MATrix LABoratory) is a high-level programming environment widely used in engineering and scientific computing for numerical computation, data analysis, algorithm development, and visualization. This introductory laboratory session covers the MATLAB interface, basic operations, variable management, and script creation.

## Objective

To navigate the MATLAB desktop environment including Command Window, Workspace, and Current Folder panes, use MATLAB as a calculator with basic arithmetic operations, create and manage variables in the workspace, write and execute simple MATLAB scripts (.m files), and understand data types including doubles, integers, and character arrays.

## Theory and Engineering Concepts

MATLAB uses a matrix-based approach to computation where all data is treated as arrays. The key interface elements include:

- **Command Window**: The primary interactive environment where commands are typed and executed. The prompt `>>` indicates MATLAB is ready for input.
- **Workspace**: Displays all currently defined variables, their values, data types, and sizes.
- **Current Folder**: File browser showing the working directory.
- **Command History**: Log of previously executed commands.
- **Editor**: Used for writing, editing, and debugging MATLAB scripts (.m files).

## Project / Task

Explore the MATLAB environment, perform basic arithmetic operations, create and manipulate variables, and write a simple script.

## Procedure / Implementation

### Step 1: Launch MATLAB

1. Start MATLAB from the Start Menu or desktop shortcut
2. Observe the default layout:
   - **Command Window** (center)
   - **Workspace** (right side)
   - **Current Folder** (left side)
   - **Command History** (below Command Window or as a separate panel)

### Step 2: Use MATLAB as a Calculator

1. Type the following in the Command Window and observe the output:
   ```matlab
   >> 5 + 3
   >> 10 - 4
   >> 6 * 7
   >> 15 / 3
   >> 2^3
   ```
2. Observe that MATLAB uses `ans` as the default variable for unassigned results

### Step 3: Create Variables

1. Create scalar variables:
   ```matlab
   >> a = 10
   >> b = 3.14
   >> c = -5
   ```
2. Observe variables appear in the Workspace pane
3. Create character variables:
   ```matlab
   >> name = 'Engineering'
   >> message = 'Hello MATLAB'
   ```

### Step 4: Basic Variable Operations

1. Perform arithmetic with variables:
   ```matlab
   >> sum = a + b
   >> product = a * c
   >> result = a / b
   ```
2. Clear variables:
   ```matlab
   >> clear a       % clears variable 'a'
   >> clear all     % clears all variables
   >> clc           % clears the Command Window
   ```

### Step 5: Create and Run a Script

1. Click **New Script** or press **Ctrl+N**
2. Type the following:
   ```matlab
   % My First MATLAB Script
   % This script calculates the area of a circle
   
   radius = 5;
   area = pi * radius^2;
   disp(['Radius: ', num2str(radius)]);
   disp(['Area: ', num2str(area)]);
   ```
3. Save as `circle_area.m`
4. Run the script by clicking **Run** or pressing **F5**
