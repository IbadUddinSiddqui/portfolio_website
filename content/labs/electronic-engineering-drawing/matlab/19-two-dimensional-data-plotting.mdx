# Two-Dimensional Data Plotting in MATLAB

## Overview

Data visualization is a critical skill for engineers to analyze, interpret, and communicate technical information. MATLAB provides comprehensive 2D plotting capabilities for creating professional graphs suitable for reports, publications, and presentations. This laboratory session covers the complete workflow from basic plotting to polished, publication-ready figures.

## Objective

To create basic 2D line plots using the `plot()` function, customize plot appearance with line styles, colors, and markers, add labels, titles, legends, and grid lines, create multiple plots in the same figure using `hold` and `subplot`, and export figures for use in documents and presentations.

## Theory and Engineering Concepts

- **Figure**: The MATLAB window that displays plots. Multiple figures can be created with `figure()`.
- **Handle Graphics**: MATLAB uses object-oriented graphics where each plot element (axes, lines, labels) is an object with properties that can be modified.
- **Plot Resolution**: The number of data points determines the smoothness of curves. Use `linspace` with sufficient points (100-1000) for smooth plots.

## Project / Task

Create four engineering plots: a sine wave with customization, an RC circuit charging/discharging waveform, subplots showing (a) voltage and (b) current, and a multi-line plot comparing frequency responses.

## Procedure / Implementation

### Step 1: Basic Line Plot

1. Create a simple sine wave plot:
   ```matlab
   x = linspace(0, 2*pi, 100);
   y = sin(x);
   plot(x, y);
   ```

### Step 2: Customized Plot

1. Create a fully customized RC charging plot:
   ```matlab
   t = linspace(0, 5, 100);  % Time (5 time constants)
   tau = 1;                   % Time constant
   Vc = 5 * (1 - exp(-t/tau)); % Charging voltage
   
   plot(t, Vc, 'b-', 'LineWidth', 2);
   xlabel('Time (seconds)');
   ylabel('Voltage (V)');
   title('RC Circuit Charging Response');
   grid on;
   legend('V_C (t) = V(1 - e^{-t/\tau})');
   xlim([0, 5]);
   ylim([0, 5.5]);
   ```

### Step 3: Multiple Data Sets on One Plot

1. Plot charging and discharging on same axes:
   ```matlab
   t_charge = linspace(0, 5, 100);
   t_discharge = linspace(0, 5, 100);
   V_charge = 5 * (1 - exp(-t_charge));
   V_discharge = 5 * exp(-t_discharge);
   
   plot(t_charge, V_charge, 'b-', 'LineWidth', 2);
   hold on;
   plot(t_discharge, V_discharge, 'r--', 'LineWidth', 2);
   hold off;
   
   xlabel('Time (\times\tau)');
   ylabel('Voltage (V)');
   title('RC Circuit Response');
   legend('Charging: V_C(t) = V(1 - e^{-t/\tau})', ...
          'Discharging: V_C(t) = Ve^{-t/\tau}', ...
          'Location', 'southeast');
   grid on;
   ```

### Step 4: Subplots

1. Create multiple plots in one figure:
   ```matlab
   t = linspace(0, 5, 100);
   
   subplot(2, 1, 1);
   plot(t, 5 * (1 - exp(-t)), 'b-', 'LineWidth', 1.5);
   ylabel('Voltage (V)');
   title('(a) Capacitor Voltage');
   grid on;
   
   subplot(2, 1, 2);
   plot(t, (5/1000) * exp(-t), 'r-', 'LineWidth', 1.5);
   xlabel('Time (\times\tau)');
   ylabel('Current (A)');
   title('(b) Capacitor Current');
   grid on;
   ```

### Step 5: Figure Formatting and Export

1. Create a publication-ready figure:
   ```matlab
   f = figure('Position', [100, 100, 800, 500]);
   set(gca, 'FontSize', 12, 'FontName', 'Times New Roman');
   set(gcf, 'Color', 'white');
   ```

### Step 6: Experiment with Plot Types

1. Try different plot types:
   ```matlab
   >> x = 1:10;
   >> y = rand(1, 10);
   >> bar(x, y)         % Bar chart
   >> stem(x, y)        % Stem plot
   >> stairs(x, y)      % Stair plot
   >> area(x, y)        % Area plot
   ```
