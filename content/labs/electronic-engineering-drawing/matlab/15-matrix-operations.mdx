# Matrix Operations in MATLAB

## Overview

Matrix operations form the foundation of MATLAB's computational capabilities. MATLAB's name is derived from MATrix LABoratory, reflecting its core strength in matrix computation. This laboratory session covers fundamental matrix operations including creation, indexing, arithmetic, transposition, inversion, and solving systems of linear equations.

## Objective

To create matrices using different methods (explicit entry, functions, concatenation), perform matrix addition, subtraction, multiplication, and element-wise operations, compute matrix transpose, determinant, and inverse, solve systems of linear equations using matrix methods, and understand the difference between matrix and element-wise operations.

## Theory and Engineering Concepts

- **Matrix Dimensions**: Specified as rows × columns. A 3×4 matrix has 3 rows and 4 columns.
- **Matrix Multiplication**: A(m×n) × B(n×p) = C(m×p). The inner dimensions must match.
- **Element-wise Operations**: Use the dot operator (.*, ./, .^) to perform operations on corresponding elements.
- **Matrix Transpose**: Swaps rows and columns. Denoted by A' in MATLAB.
- **Matrix Inverse**: A⁻¹ such that A × A⁻¹ = I (identity matrix). Only square matrices have inverses.
- **Determinant**: A scalar value that indicates whether a matrix is invertible (det ≠ 0).

## Project / Task

Create various matrices using different methods, perform matrix arithmetic operations, compute matrix properties (determinant, inverse), and solve a system of linear equations representing a circuit analysis problem.

## Procedure / Implementation

### Step 1: Matrix Creation

1. Create matrices using direct entry:
   ```matlab
   >> A = [1, 2, 3; 4, 5, 6; 7, 8, 9]
   >> B = [10, 11, 12; 13, 14, 15; 16, 17, 18]
   ```
2. Create matrices using built-in functions:
   ```matlab
   >> zeros(3, 4)      % 3x4 matrix of zeros
   >> ones(3, 3)       % 3x3 matrix of ones
   >> eye(4)           % 4x4 identity matrix
   >> rand(3, 2)       % 3x2 matrix of random numbers
   ```

### Step 2: Matrix Arithmetic

1. Matrix addition and subtraction:
   ```matlab
   >> C = A + B
   >> D = A - B
   ```
2. Scalar operations:
   ```matlab
   >> E = A * 2        % Multiply every element by 2
   >> F = A + 10       % Add 10 to every element
   ```

### Step 3: Matrix Multiplication

1. Matrix multiplication:
   ```matlab
   >> A = [1, 2; 3, 4]
   >> B = [5, 6; 7, 8]
   >> C = A * B        % Standard matrix multiplication
   ```
2. Element-wise multiplication:
   ```matlab
   >> D = A .* B       % Element-by-element multiplication
   ```

### Step 4: Matrix Transpose and Inverse

1. Transpose:
   ```matlab
   >> A = [1, 2, 3; 4, 5, 6]
   >> A_transpose = A'  % Results in 3x2 matrix
   ```
2. Determinant and inverse:
   ```matlab
   >> M = [4, 7; 2, 6]
   >> det_M = det(M)    % Determinant: 10
   >> M_inv = inv(M)    % Inverse: [0.6, -0.7; -0.2, 0.4]
   >> verify = M * M_inv  % Should be identity matrix
   ```

### Step 5: Solving Linear Systems

1. Solve the circuit equations using matrix methods:
   ```matlab
   % System of equations:
   % 2x + y = 5
   % x - 3y = -8
   
   A = [2, 1; 1, -3]
   b = [5; -8]
   x = A \ b          % Solution using left division
   % x = [1; 3] meaning x = 1, y = 3
   ```
2. Alternative method using inverse:
   ```matlab
   x = inv(A) * b
   ```
