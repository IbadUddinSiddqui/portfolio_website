# Linear Systems and Array Operations in MATLAB

## Overview

Solving systems of linear equations is a fundamental task in engineering, appearing in circuit analysis, structural mechanics, control systems, and many other fields. This laboratory session covers multiple methods for solving linear systems in MATLAB, including direct methods, iterative approaches, and advanced array operations for efficient computation.

## Objective

To solve systems of linear equations using MATLAB's backslash operator (\) and inverse method, understand the conditions for system solvability (determinant, rank), apply linear system solutions to circuit analysis using nodal and mesh analysis, use array operations for efficient element-wise computations, and analyze system properties using matrix condition number and rank.

## Theory and Engineering Concepts

A system of linear equations can be expressed in matrix form as Ax = b, where A is the coefficient matrix, x is the vector of unknowns, and b is the constant vector. The system has a unique solution if A is square and det(A) ≠ 0.

- **Condition Number**: Measures the sensitivity of the solution to small changes in the input. High condition numbers indicate ill-conditioned systems.
- **Rank**: The number of linearly independent rows or columns. A full-rank matrix has rank = min(m, n).
- **Overdetermined Systems**: More equations than unknowns (m > n). Solved using least-squares.
- **Underdetermined Systems**: More unknowns than equations (m < n). Infinite solutions exist.

## Project / Task

Solve a 3-mesh circuit analysis problem using matrix methods, analyze system properties, and compare solution methods. Solve an overdetermined system using least-squares fitting for experimental data.

## Procedure / Implementation

### Step 1: Solving a 3-Mesh Circuit

1. Define the circuit equations matrix for a 3-mesh circuit:
   ```matlab
   % Mesh equations:
   % 10I1 - 4I2 = 12
   % -4I1 + 14I2 - 5I3 = 0
   % -5I2 + 10I3 = 0
   
   R = [10, -4, 0; -4, 14, -5; 0, -5, 10];
   V = [12; 0; 0];
   I = R \ V;
   disp(['Mesh currents (A):']);
   disp(I);
   ```

### Step 2: Analyze System Properties

1. Check matrix properties:
   ```matlab
   >> det_R = det(R)        % Determinant
   >> rank_R = rank(R)      % Rank
   >> cond_R = cond(R)      % Condition number
   >> inv_R = inv(R)        % Inverse
   ```

### Step 3: Solve Using Different Methods

1. Compare solution methods:
   ```matlab
   % Method 1: Backslash (recommended)
   I1 = R \ V;
   
   % Method 2: Inverse
   I2 = inv(R) * V;
   
   % Method 3: Symbolic (if Symbolic Toolbox available)
   % syms I1 I2 I3
   % eqns = [10*I1 - 4*I2 == 12; -4*I1 + 14*I2 == 5*I3; -5*I2 + 10*I3 == 0];
   
   % Compare results
   difference = norm(I1 - I2);
   disp(['Difference between methods: ', num2str(difference)]);
   ```

### Step 4: Solve Overdetermined System (Least Squares)

1. Fit experimental data using least squares:
   ```matlab
   % Experimental data
   x = [1, 2, 3, 4, 5, 6]';
   y = [2.1, 3.9, 6.2, 7.8, 10.1, 11.9]';
   
   % Set up for linear fit: y = mx + c
   A = [x, ones(size(x))];
   coefficients = A \ y;  % m = coefficients(1), c = coefficients(2)
   m = coefficients(1);
   c = coefficients(2);
   disp(['Slope (m): ', num2str(m)]);
   disp(['Intercept (c): ', num2str(c)]);
   ```

### Step 5: Array Operations

1. Perform advanced array operations:
   ```matlab
   >> A = [1, 2, 3; 4, 5, 6; 7, 8, 9];
   >> sum(A)           % Sum of each column
   >> sum(A, 'all')   % Sum of all elements
   >> mean(A)          % Mean of each column
   >> max(A)           % Maximum of each column
   >> min(A)           % Minimum of each column
   >> sort(A)          % Sort each column
   >> diag(A)          % Extract diagonal elements
   ```
