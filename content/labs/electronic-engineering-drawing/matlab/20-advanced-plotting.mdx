# Advanced Plotting Techniques in MATLAB

## Overview

Advanced data visualization techniques enable engineers to present complex multi-dimensional data in clear, informative ways. This laboratory session covers 3D plotting, surface visualization, contour plots, color mapping, and advanced figure composition for comprehensive engineering data communication.

## Objective

To create 3D line plots using `plot3()`, generate surface and mesh plots using `surf()` and `mesh()`, produce contour plots for 2D data representation, customize colormaps and color bars for enhanced visualization, create multi-panel figure layouts for comprehensive data presentation, and generate animated plots to show time-varying data.

## Theory and Engineering Concepts

- **3D Plotting**: `plot3()` extends 2D plotting to three dimensions, useful for trajectory and parametric visualization.
- **Surface Plots**: `surf()` creates colored 3D surfaces where color represents the Z-value. `mesh()` creates wireframe surfaces.
- **Contour Plots**: `contour()` shows lines of constant Z value, useful for visualizing 2D scalar fields.
- **Colormaps**: MATLAB provides built-in colormaps (parula, jet, hot, cool, etc.) that map data values to colors.

## Project / Task

Create a comprehensive data visualization figure for a bivariate Gaussian distribution, showing: a 3D surface, contour plot, mesh plot, and color-coded heat map in a 2×2 subplot layout.

## Procedure / Implementation

### Step 1: 3D Line Plot

1. Create a 3D spiral:
   ```matlab
   t = linspace(0, 10*pi, 500);
   x = t .* cos(t);
   y = t .* sin(t);
   z = t;
   plot3(x, y, z, 'b-', 'LineWidth', 1.5);
   grid on;
   xlabel('X'); ylabel('Y'); zlabel('Z');
   title('3D Spiral');
   ```

### Step 2: Surface and Mesh Plots

1. Create a Gaussian surface:
   ```matlab
   [X, Y] = meshgrid(-3:0.1:3, -3:0.1:3);
   Z = exp(-(X.^2 + Y.^2)/2);
   
   figure(1);
   surf(X, Y, Z);
   xlabel('X'); ylabel('Y'); zlabel('Z');
   title('3D Surface Plot of Gaussian Distribution');
   colorbar;
   shading interp;  % Smooth shading
   ```

### Step 3: Contour Plot

1. Create 2D contour:
   ```matlab
   figure(2);
   contour(X, Y, Z, 20);  % 20 contour levels
   xlabel('X'); ylabel('Y');
   title('Contour Plot (20 Levels)');
   colorbar;
   grid on;
   axis equal;
   ```

### Step 4: Multi-Panel Figure (2×2)

1. Create comprehensive figure:
   ```matlab
   figure(3);
   clf;
   
   % Subplot 1: Surface
   subplot(2, 2, 1);
   surf(X, Y, Z);
   shading interp;
   title('(a) 3D Surface');
   colorbar;
   
   % Subplot 2: Mesh
   subplot(2, 2, 2);
   mesh(X, Y, Z);
   title('(b) Wireframe Mesh');
   colorbar;
   
   % Subplot 3: Contour
   subplot(2, 2, 3);
   contour(X, Y, Z, 15);
   title('(c) Contour Plot');
   colorbar;
   axis equal;
   
   % Subplot 4: Heat Map
   subplot(2, 2, 4);
   imagesc(Z);
   title('(d) Heat Map');
   colorbar;
   axis equal tight;
   ```

### Step 5: Custom Colormaps

1. Apply different colormaps:
   ```matlab
   >> colormap(jet)       % Jet colormap
   >> colormap(hot)       % Hot colormap
   >> colormap(cool)      % Cool colormap
   >> colormap(parula)    % Default MATLAB colormap
   ```
