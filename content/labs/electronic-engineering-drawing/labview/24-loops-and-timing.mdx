# Loops and Timing in LabVIEW

## Overview

Loops are essential programming structures for repetitive operations, data acquisition, and real-time monitoring. LabVIEW provides While Loops (indeterminate iterations) and For Loops (determinate iterations) with powerful features including shift registers for data retention between iterations. This laboratory session covers loop implementation, timing control, and shift register usage.

## Objective

To implement While Loops with appropriate termination conditions, use For Loops for fixed-iteration operations, use shift registers to pass data between loop iterations, control loop timing using Wait and Tick Count functions, and create a real-time data acquisition simulation with loop-based timing.

## Theory and Engineering Concepts

- **While Loop**: Executes repeatedly until a condition is met. The conditional terminal at the bottom-right determines when to stop (Stop if True or Continue if True).
- **For Loop**: Executes a predetermined number of times. The count terminal (N) specifies iterations, and the iteration terminal (i) provides the current count (0-indexed).
- **Shift Register**: A mechanism on loop borders that passes data from one iteration to the next, enabling accumulation, averaging, and state retention.
- **Timing Functions**: `Wait (ms)` provides simple timing, `Wait Until Next ms Multiple` provides precise loop timing, and `Tick Count` measures elapsed time.

## Project / Task

Create a VI that: (a) generates a sine wave using a For Loop with iteration-based calculation, (b) implements a running average filter using shift registers, and (c) creates a real-time signal monitor using a While Loop with timing control.

## Procedure / Implementation

### Step 1: While Loop Basics

1. Place a While Loop (Functions → Programming → Structures → While Loop)
2. Add a Numeric Control inside the loop for iteration counting
3. Add a Stop button outside the loop wired to the conditional terminal
4. Inside the loop, add a Wait (ms) function (set to 100ms)

### Step 2: For Loop Basics

1. Place a For Loop (Functions → Programming → Structures → For Loop)
2. Set N = 10 (right-click on N terminal → Create Constant)
3. Inside the loop, place an Increment function:
   - Wire the iteration terminal (i) through an Increment to get 1-indexed count
4. Outside the loop, wire the output tunnel to a Numeric Indicator

### Step 3: Generate Sine Wave with For Loop

1. Create a For Loop with N = 100
2. Inside the loop:
   - Divide the iteration index (i) by 10 to get theta: `theta = i / 10`
   - Apply Sine function (Functions → Mathematics → Elementary → Sine)
   - Multiply by amplitude (e.g., 5)
3. Auto-index the output array to create a 100-element waveform

### Step 4: Running Average Filter with Shift Register

1. Place a While Loop
2. Right-click the left border → Add Shift Register
3. Initialize the shift register (outside the loop):
   - Wire a 5-element array of zeros
4. Inside the loop:
   - Get new data point (simulate with Random Number function)
   - Use Build Array to add the new value and shift old values
   - Calculate the mean of the array
   - Display both raw and filtered values

### Step 5: Real-Time Signal Monitor

1. Place a While Loop
2. Configure timing:
   - Wait (ms): 50ms (20 Hz update rate)
   - Tick Count: measure elapsed time
3. Inside the loop:
   - Generate a simulated signal: `sin(time) + noise`
   - Display on a Waveform Graph
   - Check for stop condition (user button or elapsed time limit)

## What Was Done

Created a For Loop VI generating a 100-point sine wave with auto-indexed array output.
