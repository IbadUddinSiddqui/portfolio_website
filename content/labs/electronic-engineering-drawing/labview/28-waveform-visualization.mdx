# Waveform Visualization in LabVIEW

## Overview

Data visualization is a critical component of virtual instrumentation. LabVIEW provides powerful graph and chart controls for displaying and analyzing waveform data in real-time and post-acquisition modes. This laboratory session covers all major graph types, customization, and advanced visualization techniques for engineering applications.

## Objective

To understand the difference between Waveform Graphs (static) and Waveform Charts (real-time), create multi-plot displays with different waveform types, use XY Graphs for parametric data visualization, customize graph appearance including axes, grids, and colors, use cursor legends for interactive data analysis, and create a comprehensive signal visualization dashboard.

## Theory and Engineering Concepts

- **Waveform Graph**: Displays a complete data array at once. Used for post-acquisition data review. Data is passed as an array or waveform data type.
- **Waveform Chart**: Displays data points one at a time, maintaining a scrolling history buffer. Used for real-time data monitoring. Has three update modes: strip chart, scope chart, and sweep chart.
- **XY Graph**: Displays data where X values are not uniformly spaced. Used for Lissajous patterns, hysteresis curves, and parametric plots.
- **Waveform Data Type**: A special LabVIEW cluster containing start time (t0), time interval (dt), and Y data array (Y[]).

## Project / Task

Create a comprehensive signal visualization dashboard with: (a) a real-time multi-channel waveform chart showing three generated signals, (b) an XY graph displaying a Lissajous pattern, and (c) a waveform graph with cursor-based measurement for frequency and amplitude analysis.

## Procedure / Implementation

### Step 1: Waveform Graph Basics

1. Place a Waveform Graph (Controls → Graph → Waveform Graph)
2. Create a For Loop generating a 500-point sine wave
3. Wire the output array directly to the Waveform Graph
4. Run and observe the complete waveform display

### Step 2: Waveform Chart — Real-Time Display

1. Place a Waveform Chart (Controls → Graph → Waveform Chart)
2. Place a While Loop with 50ms timing
3. Inside the loop:
   - Generate a simulated signal: `sin(time) + 0.5*random()`
   - Wire the single data point to the chart
4. The chart scrolls to show the last N data points
5. Experiment with chart update modes:
   - Right-click the chart → Advanced → Update Mode
   - Try Strip Chart, Scope Chart, and Sweep Chart

### Step 3: Multi-Plot Display

1. Create three signals inside a While Loop:
   - Signal 1: 2 Hz sine wave
   - Signal 2: 5 Hz sine wave
   - Signal 3: 2 Hz sine + noise
2. Bundle the three signals into a single waveform display:
   - Use Build Array to create a 2D array (each row is a plot)
   - Or use Create Waveform function for each signal
3. Customize plot colors:
   - Right-click the graph → Plots → Color
   - Assign different colors to each signal

### Step 4: XY Graph — Lissajous Pattern

1. Place an XY Graph (Controls → Graph → XY Graph)
2. Inside a For Loop (N = 1000):
   - Generate X data: `sin(2*pi*3*t)`
   - Generate Y data: `sin(2*pi*2*t + phase_shift)`
3. Bundle X and Y arrays into the XY Graph input
4. Create a phase shift control and observe pattern changes

### Step 5: Cursor-Based Measurement

1. Add a Cursor Legend to the Waveform Graph:
   - Right-click graph → Visible Items → Cursor Legend
2. Add two cursors:
   - Right-click Cursor Legend → Create Cursor → Free
3. Use cursors to measure:
   - Peak-to-peak amplitude (Y difference)
   - Period (X difference between peaks)
   - Calculate frequency: f = 1/T

### Step 6: Graph Customization

1. Right-click the graph → Properties:
   - **Appearance**: Title, labels, colors
   - **Scales**: X and Y axis ranges, grid style, scale type (linear/log)
   - **Plots**: Line style, width, color, point style
   - **Cursors**: Cursor colors and snap modes

All graphs were customized with appropriate colors, scales, and grid settings.
