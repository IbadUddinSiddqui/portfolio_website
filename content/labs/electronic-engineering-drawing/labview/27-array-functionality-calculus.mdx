# Array Functionality and Numerical Calculus in LabVIEW

## Overview

Numerical calculus operations — differentiation and integration — are essential for analyzing engineering data, particularly for converting between physical quantities like displacement, velocity, and acceleration. This laboratory session covers advanced array manipulation and numerical calculus operations in LabVIEW using the Mathematics palette.

## Objective

To perform advanced array operations including reshaping, transpose, and subset extraction, implement numerical differentiation on sampled data arrays, implement numerical integration (trapezoidal rule) on sampled data, apply calculus operations to convert position-velocity-acceleration data, and analyze signal characteristics using derivative and integral functions.

## Theory and Engineering Concepts

- **Numerical Differentiation**: Approximates the derivative of a function from sampled data points. The simplest method uses the difference formula: `dy/dx ≈ (y_{i+1} - y_i) / (x_{i+1} - x_i)`.
- **Numerical Integration**: Approximates the definite integral using methods like the trapezoidal rule: `∫f(x)dx ≈ Σ[(f(x_i) + f(x_{i+1}))/2 × Δx]`.
- **Integration (Cumulative)**: The running sum of a signal, used to convert acceleration to velocity or velocity to position.
- **Sampling Rate**: The frequency at which data points are acquired. Higher sampling rates provide more accurate numerical calculus results.

## Project / Task

Create a VI that: generates a simulated acceleration signal, performs numerical integration to calculate velocity and position, performs numerical differentiation to verify the reverse operation, and displays all three signals on a single graph for comparison.

## Procedure / Implementation

### Step 1: Generate Simulated Acceleration Data

1. Create a For Loop with N = 1000
2. Generate a composite signal:
   ```labview
   t = i * dt  (dt = 0.01 seconds)
   acceleration = 5 * sin(2*pi*2*t) + 2 * cos(2*pi*5*t)
   ```
3. Build an array of time values (t)
4. Build an array of acceleration values

### Step 2: Numerical Integration (Trapezoidal Rule)

1. Implement using the Integration palette:
   - Functions → Mathematics → Integration & Differentiation → Integral x(t)
2. Wire acceleration array as input
3. Wire dt (time step) array or constant
4. Output is velocity array
5. Apply integration again to get position

### Step 3: Numerical Differentiation

1. Implement using the Differentiation palette:
   - Functions → Mathematics → Integration & Differentiation → Derivative x(t)
2. Wire position array as input
3. Output should match original velocity (verification)

### Step 4: Display Results

1. Create a Waveform Graph on the Front Panel
2. Bundle acceleration, velocity, and position into a single graph display
3. Use different colors for each signal
4. Add legend labels

### Step 5: Advanced Array Functions

1. Array subset extraction:
   - Extract a portion of the signal for analysis
2. Array reshaping:
   - Reshape a 1D array into a 2D array for multi-channel display
3. Transpose:
   - Transpose a 2D array for different data organization

## What Was Done

Created a complete data analysis VI that generates a simulated acceleration signal (composite of 2Hz and 5Hz sine components at 100 Hz sampling rate), performs numerical integration to calculate velocity and displacement, performs numerical differentiation to verify the reverse operation, and displays all three signals on a single waveform graph. The integration and differentiation operations showed consistent results with the original signals within numerical error bounds.
