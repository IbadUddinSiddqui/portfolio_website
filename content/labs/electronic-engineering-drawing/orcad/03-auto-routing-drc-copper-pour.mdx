# Auto Routing, Design Rules Check, and Copper Pour

## Overview

After placing components on a PCB, the next critical step is routing — creating copper traces that connect components according to the schematic netlist. This laboratory session covers automated routing using SPECCTRA, performing comprehensive design rules check (DRC), and creating copper pour areas for power distribution and EMI shielding.

## Objective

To route a PCB using the SPECCTRA auto-router, perform design rules check and resolve violations, create copper pour areas for power and ground nets, and understand thermal relief patterns for improved solderability.

## Domain

Electronic Design Automation (EDA) — PCB Routing and Design Verification.

- **CLO-3**: Perform auto-routing, DRC, and copper pour operations on a PCB layout.
- **Taxonomy Level**: C3 (Applying) — Apply auto-routing and copper pour techniques. C4 (Analyzing) — Analyze DRC violations and determine corrective actions.

## Theory and Engineering Concepts

- **Auto Routing**: The automated process of creating copper traces between component pins based on netlist connectivity. SPECCTRA uses routing algorithms to find optimal paths while respecting design constraints.
- **Design Rules Check (DRC)**: Automated verification that the PCB layout adheres to manufacturing and electrical constraints including trace widths, clearances, via sizes, and net spacing.
- **Copper Pour**: A large area of copper on a PCB layer used for power distribution (VCC), ground planes (GND), or EMI shielding. Copper pours provide low-impedance paths and reduce electromagnetic interference.
- **Thermal Relief**: A pattern of narrow traces connecting a pad to a copper pour, allowing heat to dissipate during soldering while maintaining electrical connectivity. Without thermal relief, soldering becomes difficult due to heat sinking.
- **Net Classes**: Groups of nets with specific routing constraints. Power nets typically use wider traces than signal nets.

## Project / Task

Route the LED driver PCB from Lab 02 using SPECCTRA auto-router, run DRC to verify the design, create copper pour areas for VCC and GND nets, and apply thermal relief patterns.

## Procedure / Implementation

### Step 1: Configure Auto-Router Setup

1. Open the board file from Lab 02 in OrCAD PCB Editor
2. Select **Route → PCB Router → Setup** to configure auto-router
3. In the Routing Setup dialog:
   - Select **SPECCTRA Smart Route** as the routing engine
   - Set **Routing Layers**: Top and Bottom (for 2-layer board)
   - Set **Direction**: Preferred horizontal on top, vertical on bottom
   - Set **Via Type**: Through-hole vias
4. Configure routing strategy:
   - Route order: Power nets first, then signal nets
   - Fan-out: Generate fan-outs for surface-mount components

### Step 2: Run Auto-Router

1. Select **Route → PCB Router → Route Automatic**
2. Configure auto-route parameters:
   - **Minimum via grid**: 25 mils
   - **Attempt to route**: All nets
   - **Routing effort**: Medium (balance between speed and quality)
3. Click **Route** to start the auto-routing process
4. Monitor routing progress in the status window
5. Review routing results:
   - Number of traces routed
   - Number of failed connections (if any)
   - Routing completion percentage

### Step 3: Manual Touch-Up (If Needed)

1. Review auto-routed traces for potential issues:
   - Unnecessarily long traces
   - Acute angles in traces (< 90 degrees)
   - Traces too close to board edges
2. Use **Slide** and **Edit Trace** tools to adjust problematic traces
3. Use **Vertex** command to add or remove trace vertices for cleaner routing

### Step 4: Run Design Rules Check (DRC)

1. Select **Setup → Constraints → DRC**
2. Configure DRC options:
   - Check all constraints (physical, spacing, same-net)
   - Report all violations
   - Stop on first error (optional)
3. Run DRC and review the report:
   - **DRC Errors**: Critical violations that must be fixed
   - **DRC Warnings**: Non-critical issues that should be reviewed
4. Common DRC violations:
   - Trace-to-trace spacing violation
   - Trace-to-pad spacing violation
   - Unrouted nets
   - Silkscreen overlapping pads
5. Fix all critical DRC errors before proceeding

### Step 5: Create Copper Pour for Ground Plane

1. Select the **Bottom Layer** as the active layer
2. Select **Shape → Polygon** or **Shape → Rectangular**
3. Draw a polygon covering the entire board area
4. In the shape properties dialog:
   - Assign net: **GND**
   - Layer: **Bottom**
   - Dynamic fill: **Smooth** or **Rough** (Smooth recommended for manufacturing)
5. Set copper pour parameters:
   - Clearance: **12 mils** from other nets
   - Thermal relief connection: **4 spokes** at 45 degrees
   - Minimum spoke width: **10 mils**

### Step 6: Create Copper Pour for Power Plane

1. Select the **Top Layer** as the active layer
2. Select **Shape → Polygon**
3. Draw a polygon in areas where VCC routing is concentrated
4. Assign net: **VCC**
5. Set same parameters as ground pour with appropriate clearance

### Step 7: Apply Thermal Relief Patterns

1. Select **Shape → Global Dynamic Params**
2. In **Thermal Relief** tab:
   - Enable thermal relief for all pads connecting to copper pours
   - Set connection style: **Orthogonal** or **Diagonal**
   - Spoke width: **12 mils**
   - Air gap: **8 mils**
3. Apply thermal relief to all through-hole pads

### Step 8: Final DRC After Copper Pour

1. Run DRC again after copper pour creation
2. Verify no new violations were introduced by the copper pour
3. Check thermal relief connections are properly formed
4. Review copper pour edges for sharp corners or acute angles
