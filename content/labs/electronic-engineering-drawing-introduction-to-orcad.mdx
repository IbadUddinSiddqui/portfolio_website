# Introduction to OrCAD Capture

## Overview

OrCAD Capture is a powerful schematic capture tool used in the electronic engineering industry for designing and documenting electronic circuits. This laboratory session introduces the OrCAD Capture environment, its interface, and basic operations required to create professional engineering drawings.

## Objective

- Familiarize with the OrCAD Capture user interface and workspace
- Learn to create a new project and configure design settings
- Understand component placement and wire routing techniques
- Create a basic schematic diagram with proper annotation
- Generate a bill of materials (BOM) from the schematic

## Theory / Background

Schematic capture is the first step in the electronic design automation (EDA) workflow. It involves creating a graphical representation of an electronic circuit using standardized symbols. OrCAD Capture provides:

- **Hierarchical Design**: Ability to organize complex circuits into hierarchical blocks
- **Component Libraries**: Extensive libraries of pre-built components
- **Netlist Generation**: Automatic generation of netlists for PCB layout
- **Design Rules Checking (DRC)**: Validation of schematic connectivity and rules

The schematic serves as the blueprint for PCB layout, simulation, and manufacturing.

## Required Tools

- **Software**: OrCAD Capture CIS 17.4 (or later)
- **Operating System**: Windows 10/11
- **Memory**: Minimum 8GB RAM recommended

## Skills Required

- Basic computer literacy
- Understanding of electronic components (resistors, capacitors, ICs)
- Familiarity with Windows file management

## Procedure / Implementation

### Step 1: Launch OrCAD Capture

1. Start OrCAD Capture from the Start Menu or desktop shortcut
2. The main window displays the menu bar, toolbars, project manager, and workspace area

### Step 2: Create a New Project

1. Go to **File → New → Project**
2. Enter project name: `Lab01_Basic_Circuit`
3. Select **Analog or Mixed A/D** as the project type
4. Choose a location for the project files
5. Click **OK** to create the project

### Step 3: Configure Page Size

1. Right-click on the schematic folder in the Project Manager
2. Select **Schematic Page Properties**
3. Set page size to **A4** (for engineering documentation standards)
4. Set grid spacing to **100 mils**

### Step 4: Place Components

1. Click **Place → Part** or press **P**
2. In the Place Part dialog, select library `DISCRETE`
3. Add the following components:
   - Resistor (R): `R1 = 1kΩ`, `R2 = 470Ω`
   - Capacitor (C): `C1 = 100µF`
   - LED: `LED1 = Red`
4. Click to place components on the schematic page

### Step 5: Wire the Circuit

1. Click **Place → Wire** or press **W**
2. Connect components as follows:
   - Wire from positive terminal of power supply to R1
   - Wire from R1 to LED anode
   - Wire from LED cathode to R2
   - Wire from R2 to ground
3. Use the **Place → Junction** tool at connection points

### Step 6: Add Power and Ground Symbols

1. Click **Place → Power** to add VCC symbol
2. Click **Place → Ground** to add GND symbol
3. Label power nets appropriately

### Step 7: Annotate Components

1. Select **Tools → Annotate**
2. Choose **Incremental reference update**
3. Click **OK** to automatically assign reference designators

### Step 8: Perform Design Rules Check

1. Select **Tools → Design Rules Check**
2. Run DRC to verify schematic connectivity
3. Review any warnings or errors in the session log

## What Was Done

Created a complete schematic for a basic LED driver circuit using OrCAD Capture. The circuit includes a current-limiting resistor, an LED indicator, and proper power supply connections. The design was annotated, validated with DRC, and a bill of materials was generated.
